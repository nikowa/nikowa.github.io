Status: Released | WIP

The Blue Break is a simple surfing game that I originally made for a 7 day game jam. The gameplay is very basic, but I’m proud of the presentation.

Since the jam ended, I’ve made great improvements to the engine, implementing various graphical effects, and adding rigid body physics.

I’m currently working on separating the engine from the game, so I can reuse it for my other games.
